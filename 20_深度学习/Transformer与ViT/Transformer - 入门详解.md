# Transformer - 入门详解

我们这次从零开始学习 Transformer。我会把你当作初学者来讲解，不会默认你已经理解深度学习中的各种概念，也不会只给你一堆公式让你死记硬背。

**我们的目标不是让你看完之后觉得自己懂了，而是让你真正理解 Transformer 为什么这样设计、每个模块如何工作，以及最后能够自己写出一个简单的 Transformer。**

考虑到你之前在学习 PyTorch，也在研究对抗攻击领域，我们会先把 Transformer 本身学扎实。等理解了基础结构，再去学习 ViT、VLM 等相关模型会容易很多。

# 一、Transformer 究竟是什么？

## 1.1 先理解 Transformer 解决了什么问题

假设现在有一句话：

> 小明把书放在桌子上，因为他准备晚上阅读它。

如果让计算机理解这句话，它需要知道：

- 「他」指的是谁？
- 「它」指的是什么？
- 「阅读」与「书」有什么关系？
- 「桌子」和「晚上」在这句话中分别扮演什么角色？

这些问题看起来很简单，但对于计算机来说并不简单。

计算机最初处理文本时，需要把文字转换成数字。可是，数字本身并不能直接表达文字之间的关系。

例如：

```
小明 → 1001
书   → 1002
桌子 → 1003
阅读 → 1004
```

这些数字只是示意性的编号，并没有告诉计算机「小明」和「书」之间有什么关系。

因此，我们需要一种方法，让计算机能够根据上下文学习词语之间的关系。

这就是 Transformer 所擅长的事情之一。

## 1.2 Transformer 的定义

Transformer 是一种基于注意力机制的深度学习网络架构，由 Ashish Vaswani 等人在 2017 年发表的论文《Attention Is All You Need》中提出。

它最初主要用于机器翻译等序列转换任务，后来成为自然语言处理的重要基础架构，并被广泛用于语言模型、图像识别和多模态学习等领域。

它的核心思想可以概括为：

**让序列中的每个位置，根据当前任务的需要，动态地利用其他位置的信息。**

例如，在理解：

> 小明把书放在桌子上，因为他准备晚上阅读它。

时，模型可以学习让「他」更多地关注「小明」，让「它」更多地关注「书」。

这里的「关注」不是人类意义上的有意识思考，而是模型通过计算得到不同位置的信息权重，并利用这些信息生成新的特征表示。

这种机制叫作 **Attention（注意力机制）**。

注意力机制是理解 Transformer 的关键，但要真正理解 Transformer，还需要弄清楚它的输入、计算过程、网络结构和训练方式。

我们一步一步来。

# 二、学习 Transformer 之前，需要掌握哪些基础？

你不需要先把所有数学知识学完，但需要逐渐理解下面这些概念。

|基础知识|需要理解什么|在 Transformer 中的作用|
|---|---|---|
|向量|一组数字如何表示一个对象|表示词语或图像块的特征|
|矩阵|如何组织大量向量|批量进行特征计算|
|矩阵乘法|如何将一种特征变换成另一种特征|计算 Query、Key、Value|
|神经网络|参数如何通过训练得到|学习特征表示|
|激活函数|如何引入非线性|构建复杂的特征变换|
|Softmax|如何将一组分数变成概率分布|计算注意力权重|
|梯度下降与反向传播|如何调整参数以降低误差|训练 Transformer|

如果你现在还不熟悉矩阵乘法，也没关系。我们会在用到时解释。

首先，我们从 Transformer 的输入开始。

# 三、Transformer 如何处理一句话？

## 3.1 第一步：分词 Tokenization

假设输入文本是：

```
我喜欢学习人工智能
```

计算机不能直接按照人类的方式理解这句话，因此通常需要先进行分词。

一种可能的分词结果是：

```
["我", "喜欢", "学习", "人工智能"]
```

这里的每个元素称为一个 Token。

注意：**Token 不一定等于一个汉字、一个词或者一个英文单词。**

例如，英文中的：

```
unbelievable
```

可能被拆分成：

```
["un", "believ", "able"]
```

实际拆分结果取决于所使用的分词器。

现代语言模型通常使用子词或其他基于 Token 的编码方案。

## 3.2 第二步：将 Token 转换成数字

计算机需要使用数字处理这些 Token。

假设词表中有以下映射：

|Token|Token ID|
|---|---|
|我|101|
|喜欢|205|
|学习|307|
|人工智能|412|

那么输入就变成：

```
[101, 205, 307, 412]
```

这些数字叫作 Token ID。

但是这里有一个非常重要的问题：

**Token ID 只是索引，并不直接表示 Token 的语义。**

例如，412 并不意味着「人工智能」比「我」更重要，也不意味着它们之间存在某种数值关系。

因此，我们还需要进一步处理。

## 3.3 第三步：Embedding，将 Token ID 转换成向量

Word embedding 可以理解为：把每个 Token 映射到一个可以学习的向量空间中。

例如：

```
我       → [0.2, 0.5, 0.1, 0.7]
喜欢     → [0.8, 0.3, 0.6, 0.2]
学习     → [0.4, 0.9, 0.2, 0.5]
人工智能 → [0.7, 0.6, 0.8, 0.3]
```

这里使用的只有 4 个维度，仅仅是为了方便展示。

实际 Transformer 的向量维度可能是数百甚至数千。

例如，某个模型可能使用 768 维的隐藏表示。

我们把每个 Token 对应的向量称为它的 Embedding。

在 PyTorch 中，可以使用：

```
import torchimport torch.nn as nnembedding = nn.Embedding(    num_embeddings=1000,    embedding_dim=4)token_ids = torch.tensor([101, 205, 307, 412])x = embedding(token_ids)print(x.shape)
```

输出：

```
torch.Size([4, 4])
```

为什么？

因为：

- 输入有 4 个 Token。
- 每个 Token 被映射成 4 维向量。

所以最终得到一个形状为：

$$
[ X\in\mathbb{R}^{4\times 4} ]
$$

的矩阵。

这里的 `nn.Embedding` 本质上维护一个可训练的向量表。输入 Token ID 后，它会取出对应的向量。

注意，代码中的 1000 只是演示用的词表大小，实际使用时需要与模型的词表配置相匹配。

到这里，我们已经完成了：

$$
[ \text{文本} \rightarrow \text{Token} \rightarrow \text{Token ID} \rightarrow \text{Embedding} ]
$$

但是，还有一个问题。

假设两个句子都包含「苹果」：

```
我吃了一个苹果。
苹果公司发布了新产品。
```

两个句子中的「苹果」含义不同。

如果 Embedding 只是从向量表中查出固定向量，那么这两个「苹果」一开始获得的向量是相同的。

Transformer 如何区分它们？

**答案是：通过上下文计算，让 Token 的表示发生变化。**

这正是接下来要学习的核心内容。

# 四、Transformer 的核心：Self-Attention

如果你只能记住 Transformer 中的一个核心概念，那么应该记住：

**Self-Attention（自注意力机制）。**

我们先不着急看复杂公式，先通过一个例子理解它的工作方式。

## 4.1 为什么需要 Self-Attention？

考虑下面这句话：

> 小明喜欢小红，因为她很聪明。

假设我们要理解「她」这个 Token。

如果模型只处理「她」自身的初始向量，它就无法直接从这个向量中获得当前句子里的全部信息。

但在这句话中，「她」与「小红」存在较强的语义联系。

因此，模型需要综合其他 Token 的信息，更新「她」的表示。

可以把这个过程理解成：

```
小明     ──┐
喜欢     ──┤
小红     ──┤
因为     ──┼──→ 计算彼此之间的相关程度
她       ──┤
很       ──┤
聪明     ──┘
                  ↓
          更新每个 Token 的表示
```

上图只是说明信息交互的过程，并不意味着每个 Token 在所有任务中都以同样的方式关注其他 Token。

Self-Attention 会根据输入内容计算不同位置之间的注意力权重。

## 4.2 Self-Attention 到底是什么？

把这个词拆开：

- Self：自身。
- Attention：注意力。

为什么叫「自注意力」？

**即计算某个位置的新表示时，使用的信息来自同一个输入序列中的其他位置，也包括它自己。**

例如：

```
输入序列：

[小明, 喜欢, 小红, 因为, 她, 很, 聪明]
```

计算「她」的新表示时，模型可以根据训练得到的规律，利用「小明」「小红」「聪明」等位置的信息。

具体利用哪些位置、各自利用多少，由**注意力计算**决定。

需要注意：注意力权重不一定等于人类直觉中的语法关系，也不能简单地把它当作模型全部决策过程的解释。

# 五、Q、K、V 是什么？这是最重要的一关

当你第一次接触 Transformer 时，很可能会看到三个字母：

$$
[ Q,\quad K,\quad V ]
$$

它们分别表示：

- **Q：Query，查询向量**
- **K：Key，键向量**
- **V：Value，值向量**

你可能会问：

为什么好端端的注意力机制，要引入三个向量？

我们从一个容易理解的类比开始。

## 5.1 用图书馆来理解 Q、K、V

假设你来到图书馆，想找一本关于深度学习的书。

每本书都有两个方面的信息：

1. **书的索引信息**，用于判断它是否符合你的需求。
2. **书的实际内容**，用于提供你想要的信息。

我们可以作如下类比：

| 图书馆中的概念    | Transformer 中的概念 |
| ---------- | ---------------- |
| 你的查询需求     | Query（Q）         |
| 每本书的索引特征   | Key（K）           |
| 每本书的实际内容   | Value（V）         |
| 查询与索引的匹配程度 | 注意力分数            |
| 从相关书籍中提取信息 | 加权求和 Value       |

这里的类比只是为了帮助你理解，不是说 Transformer 内部真的存在一个图书馆。

对于输入序列中的某个 Token：

- Q 表示它用于**查询其他位置的特征**。
- K 表示它**提供给其他位置**进行匹配的特征。
- V 表示它可以**向其他位置提供的内容**。

**Q 和 K 用来计算注意力权重，V 用来按照这些权重汇总信息。**

这是整个注意力机制的核心逻辑。

## 5.2 Q、K、V 是怎么计算出来的？

假设输入序列经过 Embedding 后，得到：

$$
[ X\in\mathbb{R}^{n\times d_{\text{model}}} ]
$$

其中：

- $(n)$：Token 的数量。
- $(d_{\text{model}})$：每个 Token 的特征维度。

为了方便理解，假设：

$$
[ n=3,\qquad d_{\text{model}}=4 ]
$$

那么：

$$
[ X\in\mathbb{R}^{3\times4} ]
$$

也就是说，有 3 个 Token，每个 Token 对应一个 4 维向量。

接下来，Transformer 使用三个可学习的线性变换：

$$
[ Q=XW_Q ]
$$
$$
[ K=XW_K ]
$$
$$
[ V=XW_V ]
$$

其中：

- $(W_Q)$：生成 Query 的参数矩阵。
- $(W_K)$：生成 Key 的参数矩阵。
- $(W_V)$：生成 Value 的参数矩阵。

在这个简化例子中，可以假设三个矩阵的形状都是：

$$
[ 4\times4 ]
$$

于是：

$$
[ (3\times4)(4\times4)=3\times4 ]
$$

因此：

$$
[ Q,K,V\in\mathbb{R}^{3\times4} ]
$$

注意：这些矩阵中的参数不是人为规定的固定数值，而是模型在训练过程中通过反向传播学习得到的。

为什么要使用三个不同的矩阵？

因为模型需要学习不同的特征变换方式：

- 哪些特征适合用来发起查询。
- 哪些特征适合用来进行匹配。
- 哪些特征适合用于信息传递。

它们虽然来自同一个输入 $(X)$，但经过不同的参数矩阵后，可以携带不同的信息。

# 六、Attention 的数学计算过程

现在我们已经得到了 Q、K、V。

接下来，要让模型知道：

**每个 Token 应该从其他 Token 那里获取多少信息？**

这需要经历三个步骤：

1. 计算注意力分数。
2. 使用 Softmax 将分数转换为权重。
3. 根据权重对 V 进行加权求和。

我们逐个分析。

## 6.1 第一步：计算 Q 和 K 的匹配分数

注意力分数矩阵的计算方式是：

$$
[ S=QK^T ]
$$

这里的 $(K^T)$ 表示 K 的转置。

假设：

$$
[ Q\in\mathbb{R}^{3\times4} ]
$$
$$
[ K\in\mathbb{R}^{3\times4} ]
$$

那么：

$$
[ K^T\in\mathbb{R}^{4\times3} ]
$$

因此：

$$
[ QK^T\in\mathbb{R}^{3\times3} ]
$$

为什么最后得到一个 $(3\times3)$ 的矩阵？

因为输入序列中有 3 个 Token，而每个 Token 都需要计算它与 3 个 Token 的匹配分数。

例如：

$$
[ S= \begin{bmatrix} 2&1&0\\ 1&3&2\\ 0&2&4 \end{bmatrix} ]
$$

这是一个为了演示而构造的分数矩阵，并非训练模型实际计算出的结果。

其中：

- 第一行：第一个 Token 对所有 Token 的匹配分数。
- 第二行：第二个 Token 对所有 Token 的匹配分数。
- 第三行：第三个 Token 对所有 Token 的匹配分数。

例如，第二行：

$$
[ [1,3,2] ]
$$

表示第二个 Token 对三个位置计算得到的原始匹配分数分别为 1、3、2。

在这个示例中，它与第二个 Token 的匹配分数最高。

但请注意：这里的分数还不是概率，也不能直接理解为百分比。

## 6.2 第二步：为什么要除以平方根？

Transformer 使用的标准缩放点积注意力公式是：

$$
[ \boxed{ \operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left( \frac{QK^T}{\sqrt{d_k}} \right)V } ]
$$

这是你需要重点掌握的公式。

我们先看其中的：

$$
[ \frac{QK^T}{\sqrt{d_k}} ]
$$

这里的 $(d_k)$ 是 Key 向量的维度。

假设：

$$
[ d_k=64 ]
$$

那么：

$$
[ \sqrt{d_k}=\sqrt{64}=8 ]
$$

于是原始分数需要除以 8。

为什么要这样做？

当向量维度较大时，如果各个分量的数值具有适当的、近似独立的统计特征，那么点积的数值尺度通常会随着维度增加而增大。

分数过大时，Softmax 的输出容易变得极端。

例如：

$$
[ \operatorname{softmax}([1,2,3]) \approx [0.090,0.245,0.665] ]
$$

而：

$$
[ \operatorname{softmax}([10,20,30]) \approx [0.000,0.000,1.000] ]
$$

第二组结果几乎全部集中在最后一个位置。

当 Softmax 进入过于饱和的区域时，梯度可能变得很小，从而影响训练。

因此，Transformer 通过除以 $(\sqrt{d_k})$ 对点积进行缩放，使分数的尺度更加合适。

这里不要求你立刻理解完整的统计学推导。现阶段只需要记住：

**缩放的目的是控制点积分数的尺度，让注意力机制更容易稳定训练。**

## 6.3 第三步：Softmax 把分数变成权重

Softmax 的公式为：

$$
[ \operatorname{softmax}(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}} ]
$$

它有两个重要特点：

1. 输出的每个值都大于 0。
2. 一组输出的总和等于 1。

假设某个 Token 得到的分数是：

$$
[ [1,2,3] ]
$$

经过 Softmax 后：

$$
[ [0.090,0.245,0.665] ]
$$

这三个值可以看作该 Token 对三个位置分配的注意力权重。

从数值上看：

- 第一个位置的权重约为 0.090。
- 第二个位置的权重约为 0.245。
- 第三个位置的权重约为 0.665。

第三个位置的权重最大。

注意，这些权重并不是模型直接预测出来的独立标签，而是由当前 Q、K 的分数经过 Softmax 计算得到的。

## 6.4 第四步：根据权重汇总 V

假设三个位置的 Value 向量分别为：

$$
[ V_1=[1,0] ]
$$
$$
[ V_2=[0,2] ]
$$
$$
[ V_3=[2,1] ]
$$

为了方便手算，这里假设 Value 只有两个维度。

对应的注意力权重是：

$$
[ [0.090,0.245,0.665] ]
$$

那么输出就是：
$$
[ O=0.090V_1+0.245V_2+0.665V_3 ]
$$

将向量代入：

$$
[ O= 0.090[1,0] + 0.245[0,2] + 0.665[2,1] ]
$$

分别计算两个维度：

第一个维度：

$$
[ 0.090\times1 + 0.245\times0 + 0.665\times2 =1.420 ]
$$

第二个维度：

$$
[ 0.090\times0 + 0.245\times2 + 0.665\times1 =1.155 ]
$$

所以：

$$
[ \boxed{O=[1.420,1.155]} ]
$$

这就是一次注意力计算的结果。

注意力机制并不是简单地从三个向量中挑出一个，而是根据权重，将多个 Value 向量的信息融合起来。

经过这种计算，每个 Token 都能获得结合上下文的信息表示。

### 到这里，你应该真正理解了什么？

整个过程可以概括为：

$$
[ \boxed{ X \rightarrow Q,K,V \rightarrow QK^T \rightarrow \operatorname{Softmax} \rightarrow \operatorname{加权求和}(V) } ]
$$

更直观地说：

1. 从输入生成 Q、K、V。
2. 使用 Q 和 K 计算各个位置之间的匹配分数。
3. 通过 Softmax 得到注意力权重。
4. 使用注意力权重对 V 加权求和。
5. 得到融合上下文信息后的新表示。

# 七、Multi-Head Attention：为什么要有多个注意力头？

如果你已经理解了前面的 Self-Attention，那么接下来就比较容易了。

Transformer 不仅使用一个注意力计算过程，还可以同时使用多个注意力头。

这叫作：

Multi-head attention，即多头注意力。

## 7.1 只有一个注意力头有什么问题？

假设有一句话：

> 小明昨天在北京买了一本关于机器学习的书。

理解这句话时，模型可能需要学习多种关系，例如：

- 「小明」与「买」之间的关系。
- 「昨天」与事件发生时间之间的关系。
- 「北京」与事件发生地点之间的关系。
- 「机器学习」与「书」之间的关系。

一个注意力头也可以学习复杂关系，**但如果使用多个头，模型就有机会通过不同的投影空间学习不同类型的特征关系**。

需要注意：这些关系并不是被人为固定分配给不同的头，而是通过训练形成的。不能保证某个头一定专门负责时间，另一个头一定专门负责地点。

## 7.2 多头注意力如何计算？

假设输入维度为：

$$
[ d_{\text{model}}=512 ]
$$

我们使用：

$$
[ h=8 ]
$$

个注意力头。

在常见的 Transformer 多头注意力设计中，每个头的 Q、K、V 维度可以设为：

$$
[ d_k=d_v=\frac{512}{8}=64 ]
$$

每个头独立执行一次缩放点积注意力：

$$
[ \operatorname{head}_i = \operatorname{Attention} (Q_i,K_i,V_i) ]
$$

然后将所有头的输出拼接：

$$
[ \operatorname{Concat} (\operatorname{head}_1,\ldots,\operatorname{head}_8) ]
$$

最后经过一个线性变换：

$$
[ \boxed{ \operatorname{MultiHead}(Q,K,V) = \operatorname{Concat} (\operatorname{head}_1,\ldots,\operatorname{head}_8)W_O } ]
$$

其中 $(W_O)$ 是输出投影矩阵。

整个过程可以表示为：

```
                    输入 X
                       |
           +-----------+-----------+
           |           |           |
        注意力头1    注意力头2    注意力头8
           |           |           |
         输出1       输出2       输出8
           |           |           |
           +-----------+-----------+
                       |
                     拼接
                       |
                    线性变换
                       |
                 多头注意力输出
```

## 7.3 多头注意力的本质

你可以把它理解为：

**使用多组不同的可学习投影，同时从不同特征空间计算注意力，再将这些结果融合。**

这里有两个重要细节。

第一，各个注意力头通常拥有各自的 Q、K、V 投影参数。

第二，多头注意力的最终结果还要经过输出投影 $(W_O)$，而不只是简单拼接。

在实际代码中，框架通常会把多个头的计算合并成更高效的矩阵运算，而不是一定要逐个头循环执行。

# 八、Positional Encoding：Transformer 为什么需要位置信息？

现在我们已经学习了 Embedding、Self-Attention 和 Multi-Head Attention。

但还有一个问题。

假设我们有两句话：

```
小明喜欢小红
小红喜欢小明
```

这两句话包含相同的 Token，但意思明显不同。

如果只考虑普通的、没有位置编码的 Self-Attention，那么模型在构造输入时会遇到一个重要问题：

**它需要知道每个 Token 在序列中的位置。**

标准的 Self-Attention **本身并不会自动编码序列的绝对位置**。

这就是位置编码要解决的问题。

## 8.1 位置编码是什么？

位置编码（Positional Encoding）用于向模型提供有关 Token 顺序的信息。

在原始 Transformer 中，作者采用了基于**正弦和余弦函数**的位置编码。

其公式为：

$$
[ PE(pos,2i) = \sin\left( \frac{pos}{10000^{2i/d_{\text{model}}}} \right) ]
$$
$$
[ PE(pos,2i+1) = \cos\left( \frac{pos}{10000^{2i/d_{\text{model}}}} \right) ]
$$

其中：

- $(pos)$：Token 在序列中的位置。
- $(i)$：向量维度对应的索引。
- $(d_{\text{model}})$：模型的特征维度。

你暂时不需要死记这两个公式。

现在先理解：它们可以为不同位置生成不同的向量，使模型能够获得位置信息。

## 8.2 如何把位置编码加入 Embedding？

在原始 Transformer 的编码器和解码器中，Token Embedding 与位置编码会相加：

$$
[ \boxed{X=E+PE} ]
$$

其中：

- $(E)$：Token Embedding。
- $(PE)$：位置编码。

假设某个 Token 的 Embedding 是：

$$
[ E=[0.2,0.5,0.1,0.7] ]
$$

对应的位置编码是：

$$
[ PE=[0.1,0.3,0.4,0.2] ]
$$

那么输入 Transformer 的向量就是：

$$
[ X=[0.3,0.8,0.5,0.9] ]
$$

这里的数值同样只是演示。

除了正弦、余弦位置编码，现代 Transformer 还会使用可学习的位置嵌入、旋转位置编码（RoPE）以及其他**位置表示方法**。

不同模型的设计并不完全相同。

### 这一节的核心

Embedding 告诉模型 Token 的初始表示。

位置编码则提供 Token 的位置信息。

二者结合后，模型才能更好地处理序列中的内容与顺序。

# 九、Transformer 的完整结构是什么样的？

现在，我们终于可以把前面学过的模块组合起来。

原始 Transformer 主要由两大部分构成：

1. Encoder（编码器）。
2. Decoder（解码器）。

原始 Transformer 论文使用编码器—解码器结构来完成机器翻译任务。

## 9.1 Encoder：编码器

编码器负责对输入序列进行特征变换。

一个标准的原始 Transformer Encoder Layer 主要包括：

1. Multi-Head Self-Attention。
2. 残差连接与 Layer Normalization。
3. Feed-Forward Network。
4. 残差连接与 Layer Normalization。

可以简化理解为：

```
输入 X
  |
多头自注意力
  |
残差连接 + LayerNorm
  |
前馈神经网络 FFN
  |
残差连接 + LayerNorm
  |
输出
```

注意，原始 Transformer 论文使用的是 Post-LayerNorm 结构，即先执行子层计算与残差相加，再执行 LayerNorm。

现代模型也常采用 Pre-LayerNorm 等变体，因此实际顺序需要以具体模型的结构为准。

我们继续逐个理解。

## 9.2 残差连接：Residual Connection

残差连接通常写成：

$$
[ \boxed{Y=X+F(X)} ]
$$

其中：

- $(X)$：输入。
- $(F(X))$：某个神经网络子层计算出的结果。
- $(Y)$：残差相加后的结果。

例如：

$$
[ X=[1,2,3] ]
$$
$$
[ F(X)=[0.1,0.2,0.3] ]
$$

那么：

$$
[ Y=[1.1,2.2,3.3] ]
$$

为什么要这么做？

如果神经网络层数很多，直接让信息连续通过复杂的变换，可能会使训练变得困难。

残差连接为输入信息提供了一条直接的传递路径，也有助于梯度传播。

因此，它是深层 Transformer 中非常重要的设计。

## 9.3 Layer Normalization：层归一化

Layer normalization 是一种归一化方法。

它通常针对单个样本的特征维度计算均值与方差，再对特征进行标准化，并通过可学习参数进行缩放与平移。

简化形式为：

$$
[ \hat{x} = \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} ]
$$

再进行：

$$
[ y=\gamma\hat{x}+\beta ]
$$

其中：

- $(\mu)$：需要归一化的特征的均值。
- $(\sigma^2)$：对应的方差。
- $(\epsilon)$：用于数值稳定的小常数。
- $(\gamma,\beta)$：可学习参数。

它有助于稳定训练过程。

你不必现在就推导所有细节，先知道它在 Transformer 中的作用即可。

## 9.4 Feed-Forward Network：前馈神经网络

有些人学习 Transformer 时，会过度关注 Attention，却忽略了 FFN。

事实上，FFN 同样是重要组成部分。

一个常见的 FFN 形式是：

$$
[ \boxed{ \operatorname{FFN}(x) = W_2\,\sigma(W_1x+b_1)+b_2 } ]
$$

其中：

- $(W_1,W_2)$：可学习的权重矩阵。
- $(b_1,b_2)$：偏置。
- $(\sigma)$：非线性激活函数。

例如，可以使用 ReLU：

$$
[ \operatorname{ReLU}(x)=\max(0,x) ]
$$

FFN 通常先将特征映射到更高维的空间，再通过非线性变换，映射回模型的隐藏维度。

在原始 Transformer 中，前馈网络通常独立地应用于序列中每个位置。

注意，FFN 并不负责像 Self-Attention 那样直接混合不同位置的特征；它主要在每个位置上进行特征变换。

你可以这样理解：

- Self-Attention：让不同 Token 交换信息。
- FFN：进一步加工每个 Token 已经获得的特征。

两者相互配合，构成一个 Encoder Layer 的核心。

# 十、Decoder：解码器是干什么的？

如果你理解了 Encoder，Decoder 就更容易学习了。

在原始 Transformer 中，Decoder 主要用于根据输入序列和已经生成的目标序列，逐步预测下一个 Token。

例如，机器翻译任务：

```
输入：I love you

输出：我 爱 你
```

Encoder 先对输入进行编码。

Decoder 再利用 Encoder 的输出和已经生成的目标 Token，逐步生成翻译结果。

一个原始 Transformer Decoder Layer 包含三类主要子层：

1. Masked Multi-Head Self-Attention。
2. Encoder–Decoder Attention。
3. Feed-Forward Network。

每个子层还配有残差连接与 Layer Normalization。

## 10.1 Masked Self-Attention：为什么需要掩码？

假设 Decoder 正在训练以下目标序列：

```
我 爱 你
```

当模型预测「爱」时，它不应该提前看到后面的「你」。

当模型预测「你」时，它可以利用前面的「我」和「爱」。

这种限制通过因果掩码实现，通常称为 Causal Mask 或 Look-Ahead Mask。

假设序列长度为 3，对应的注意力掩码可以示意为：

$$
[ M= \begin{bmatrix} 0&-\infty&-\infty\\ 0&0&-\infty\\ 0&0&0 \end{bmatrix} ]
$$

这个矩阵加到注意力分数上。

经过 Softmax 后，被屏蔽位置的权重为 0。

因此：

- 第一个位置只能关注第一个位置。
- 第二个位置可以关注前两个位置。
- 第三个位置可以关注前三个位置。

这保证了模型在预测某个 Token 时，不会通过注意力直接读取未来 Token 的信息。

在实际训练中，目标序列还通常会进行右移，让输入位置与需要预测的下一个 Token 对齐。

## 10.2 Encoder–Decoder Attention：编码器与解码器如何交互？

这一层也叫交叉注意力（Cross-Attention）。

它与 Self-Attention 的关键区别是：

**Query 来自 Decoder，而 Key 和 Value 来自 Encoder。**

写成公式就是：

$$
[ Q=H_DW_Q ]
$$
$$
[ K=H_EW_K ]
$$
$$
[ V=H_EW_V ]
$$

其中：

- $(H_D)$：Decoder 当前的隐藏表示。
- $(H_E)$：Encoder 输出的隐藏表示。

接下来仍然使用缩放点积注意力：

$$
[ \operatorname{CrossAttention} = \operatorname{softmax} \left( \frac{QK^T}{\sqrt{d_k}} \right)V ]
$$

这使 Decoder 能够根据当前生成任务，从输入序列中提取相关信息。

例如，当模型要生成中文译文中的「北京」时，它可以利用输入句子中与北京相关的编码表示。

当然，实际注意力权重由模型计算决定，而不是人为指定。

## 10.3 Decoder 如何生成最终结果？

经过多个 Decoder Layer 后，模型得到最后的隐藏表示。

然后通常通过线性层，将隐藏维度映射到词表大小：

$$
[ \text{Logits}=HW_{\text{vocab}}+b ]
$$

假设词表有 50,000 个 Token，那么每个生成位置就会得到 50,000 个分数。

接下来通过 Softmax，可以得到每个 Token 对应的预测概率。

例如：

|Token|预测概率|
|---|---|
|北京|0.72|
|上海|0.15|
|南京|0.08|
|其他 Token|0.05|

这只是一个简化示例。

模型可以根据这些分数选择下一个 Token。具体选择方式可能是贪心解码、束搜索或采样等。

随后，将生成的 Token 作为后续输入的一部分，继续生成下一个 Token。

这个过程一直持续到满足停止条件。

# 十一、Encoder、Decoder 和现代大语言模型有什么关系？

这是一个很容易混淆的问题。

Transformer 是一种网络架构，而不是某一种特定模型的名字。

不同模型可以采用不同的 Transformer 结构。

常见的类型包括：

|架构类型|主要特点|典型代表|
|---|---|---|
|Encoder-only|主要利用双向上下文构建表示|BERT|
|Decoder-only|使用因果注意力，逐步预测后续 Token|GPT|
|Encoder–Decoder|编码输入，再根据输入和目标前缀生成输出|T5|

需要注意，这里说的是典型设计，不意味着所有模型都必须完全遵循这些形式。

### Encoder-only

这类模型适合学习上下文表示，可以用于文本分类、实体识别等任务。

例如，BERT 通过双向上下文学习文本表示，经典预训练目标包括 Masked Language Modeling。

### Decoder-only

这类模型通常使用因果注意力。

在生成某个 Token 时，模型只能利用当前 Token 及其之前的上下文，而不能直接关注未来 Token。

许多现代生成式语言模型采用这种结构。

### Encoder–Decoder

这类模型将输入编码和输出生成分开处理。

它适合机器翻译、摘要生成等输入与输出之间具有明确转换关系的任务。

**请记住：Transformer、BERT、GPT 不是同一层级的概念。**

Transformer 是架构；BERT、GPT 等是基于特定架构设计的模型。

# 十二、现在动手：用 PyTorch 实现 Self-Attention

前面学习的是数学原理。

现在，我们通过代码把公式真正运行起来。

如果你已经安装了 PyTorch，可以新建一个文件：

```
self_attention.py
```

然后写入下面的代码。

```
import mathimport torchimport torch.nn as nnclass SelfAttention(nn.Module):    def __init__(self, d_model):        super().__init__()        # 分别生成 Q、K、V        self.W_q = nn.Linear(d_model, d_model)        self.W_k = nn.Linear(d_model, d_model)        self.W_v = nn.Linear(d_model, d_model)    def forward(self, x):        # x 的形状：[batch_size, seq_len, d_model]        # 1. 生成 Q、K、V        Q = self.W_q(x)        K = self.W_k(x)        V = self.W_v(x)        # 2. 计算注意力分数        scores = Q @ K.transpose(-2, -1)        # 3. 缩放分数        d_k = Q.size(-1)        scores = scores / math.sqrt(d_k)        # 4. 对最后一个维度执行 Softmax        weights = torch.softmax(scores, dim=-1)        # 5. 使用注意力权重对 V 加权求和        output = weights @ V        return output, weights
```

## 12.1 运行后应该看到什么？

输入形状：

```
torch.Size([1, 3, 4])
```

注意力权重形状：

```
torch.Size([1, 3, 3])
```

输出形状：

```
torch.Size([1, 3, 4])
```

我们逐个解释。

### 为什么输入是 `[1, 3, 4]`？

三个维度分别表示：

- `1`：一次输入 1 个样本。
- `3`：每个样本包含 3 个 Token。
- `4`：每个 Token 的特征维度是 4。

所以：

$$
[ X\in\mathbb{R}^{1\times3\times4} ]
$$

### 为什么注意力权重是 `[1, 3, 3]`？

因为每个 Token 都需要对 3 个 Token 计算注意力权重。

因此：

$$
[ A\in\mathbb{R}^{1\times3\times3} ]
$$

如果没有额外的掩码，每一行经过 Softmax 后的权重之和应当约等于 1。

### 为什么输出还是 `[1, 3, 4]`？

注意力计算会对 Value 向量加权求和。

虽然每个 Token 都会利用其他位置的信息，但输出仍然需要为每个 Token 保留一个 4 维表示。

因此：

$$
[ O\in\mathbb{R}^{1\times3\times4} ]
$$

注意：这里的输入是随机生成的向量，并不是实际的中文或英文文本。我们目前只是在验证 Self-Attention 的计算过程。

# 十三、进一步理解：为什么注意力权重可以学习？

你可能已经发现，上面代码中的 Q、K、V 都通过 `nn.Linear` 计算得到。

那么，这些线性层的参数是怎么确定的？

答案是：通过训练。

假设我们正在训练一个文本分类模型。

输入：

```
这部电影非常精彩
```

模型需要输出：

```
正面评价
```

训练时，我们会比较模型预测结果与正确标签之间的差异，得到损失函数：

\[ L \]

接下来，通过反向传播计算各个可训练参数的梯度。

例如：

$$
[ \frac{\partial L}{\partial W_Q} ]
$$
$$
[ \frac{\partial L}{\partial W_K} ]
$$
$$
[ \frac{\partial L}{\partial W_V} ]
$$

然后，优化器根据梯度更新参数。

例如，使用 SGD 时：

$$
[ W_Q \leftarrow W_Q-\eta \frac{\partial L}{\partial W_Q} ]
$$

其中：

- $(\eta)$：学习率。
- $(\frac{\partial L}{\partial W_Q})$：损失函数对参数的梯度。

随着训练进行，模型会逐渐学会哪些特征变换有利于降低任务损失。

因此，注意力权重不是人工规定的固定表格，而是由输入和模型的可学习参数共同决定的。

这里还有一个重要区别：

**Softmax 本身通常没有需要训练的参数，但它前面的 Q、K 投影矩阵具有可学习参数。**

模型通过训练这些参数，间接影响最终的注意力分布。

# 十四、用一张图把整个 Transformer 串起来

前面涉及了很多概念，现在我们把它们整理成一条完整的处理流程。

对于原始 Encoder–Decoder Transformer，可以概括为：

## 输入阶段

```
原始文本
   ↓
Tokenization
   ↓
Token ID
   ↓
Embedding
   ↓
加入位置信息
   ↓
输入向量
```

## Encoder 阶段

```
输入向量
   ↓
Multi-Head Self-Attention
   ↓
残差连接 + LayerNorm
   ↓
Feed-Forward Network
   ↓
残差连接 + LayerNorm
   ↓
重复多个 Encoder Layer
   ↓
Encoder 输出
```

## Decoder 阶段

```
已经生成的目标 Token
   ↓
Embedding + 位置信息
   ↓
Masked Self-Attention
   ↓
残差连接 + LayerNorm
   ↓
Cross-Attention
   ↑
利用 Encoder 输出
   ↓
残差连接 + LayerNorm
   ↓
Feed-Forward Network
   ↓
残差连接 + LayerNorm
   ↓
重复多个 Decoder Layer
   ↓
线性层映射到词表
   ↓
预测下一个 Token
```

这是原始 Transformer 的典型结构示意。

需要记住的是，现代 Transformer 模型可以对这些组件进行修改、简化或替换，并不一定完整保留原始结构。

# 十六、接下来怎么学？给你安排一条真正能学会的路线

我不建议你现在就直接阅读完整的 Transformer 论文。

原因很简单：如果你对矩阵乘法、Softmax、反向传播还不熟悉，直接阅读论文会遇到大量符号，容易变成机械记忆。

我更建议按照下面的顺序学习。

### 第一阶段：打牢基础

学习内容：

- 向量与矩阵。
- 矩阵乘法。
- Softmax。
- 神经网络中的线性层。
- 前向传播与反向传播。

目标：看到 \(QK^T\) 时，能够理解它为什么产生注意力分数矩阵。

### 第二阶段：深入学习 Attention

学习内容：

- Q、K、V 的来源。
- 缩放点积注意力的数学推导。
- 注意力权重的含义。
- Self-Attention 的计算过程。
- 多头注意力的实现。

目标：能够不看资料，自己推导一次完整的 Attention 计算。

学习内容：

# 十七、现在来检验一下：你是不是真的理解了？

不要急着往后学。

你可以先尝试回答下面 5 道题。它们不是考试，而是帮助我们找出你真正不理解的地方。

**第 1 题：Embedding**

**第 2 题：Q、K、V**

在 Self-Attention 中，Q、K、V 分别起什么作用？

**第 3 题：Attention 公式**

已知：

$$
[ \operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left( \frac{QK^T}{\sqrt{d_k}} \right)V ]
$$

请解释为什么需要先计算 $(QK^T)$，再通过 Softmax，最后与 V 相乘。

**第 4 题：多头注意力**

为什么 Transformer 不只使用一个注意力头，而要使用多个注意力头？

**第 5 题：Encoder 和 Decoder**

原始 Transformer 的 Encoder 与 Decoder 有什么区别？为什么 Decoder 需要 Masked Self-Attention？
