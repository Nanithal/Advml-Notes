# 总结 - 网络结构

## 内容总结

MLP、CNN 与 RNN 分别建立全连接、局部卷积和序列建模的基础；FCN、U-Net 与采样笔记组成分割路线；AE、DEC 和 DSC 组成表示与聚类路线。

- 网络讲解与对应论文成对阅读。
- 区分分类、分割、重构和聚类的输出目标。

- [[20_深度学习/网络结构/DSC - 深度子空间聚类|DSC - 深度子空间聚类]]：围绕“DSC - 深度子空间聚类”，整理DSC 的整体网络架构全景、编码器（Encoder, $E_\theta$）、自表达层（Self-Expressive Layer）。
- [[20_深度学习/网络结构/FCN - 全卷积网络|FCN - 全卷积网络]]：围绕“FCN - 全卷积网络”，整理核心动机：为什么传统 CNN 无法直接做语义分割？、FCN 的三大核心技术创新、全卷积化（Convolutionalization）。
- [[20_深度学习/网络结构/MLP - 多层感知机|MLP - 多层感知机]]：围绕“MLP - 多层感知机”，整理MLP 的网络结构、前向传播（Forward Propagation）的数学细节、符号定义：。
- [[20_深度学习/网络结构/RNN - 循环神经网络|RNN - 循环神经网络]]：围绕“RNN - 循环神经网络”，整理RNN详解、核心动机：为什么需要 RNN？、RNN 的结构与数学原理。
- [[20_深度学习/网络结构/U-Net - 编码器与解码器分割网络|U-Net - 编码器与解码器分割网络]]：围绕“U-Net - 编码器与解码器分割网络”，整理U-Net 的设计背景：为什么医学图像需要它？、U-Net 架构全景剖析、左侧：收缩路径（Contracting Path / Encoder）。
- [[20_深度学习/网络结构/采样 - 上采样与下采样|采样 - 上采样与下采样]]：围绕“采样 - 上采样与下采样”，整理上采样 & 下采样、下采样 Down‑sampling（降采样）、为什么要做下采样。
- [[20_深度学习/网络结构/论文 - Fully Convolutional Networks for Semantic Segmentation|论文 - Fully Convolutional Networks for Semantic Segmentation]]：围绕“论文 - Fully Convolutional Networks for Semantic Segmentation”，整理研究背景与核心问题、核心方法：全卷积网络（FCN）、将全连接层转化为卷积层（Convolutionalization）。
- [[20_深度学习/网络结构/论文 - Learning Deep Features for Discriminative Localization|论文 - Learning Deep Features for Discriminative Localization]]：围绕“论文 - Learning Deep Features for Discriminative Localization”，整理研究背景与动机、核心方法：类激活映射（CAM）、弱监督目标定位实验（ILSVRC 2014）。
