# 神经网络 - 权重初始化

# 神经网络权重初始化

> 核心目的：**不让激活输出过早饱和、避免梯度消失 / 爆炸，保证前向、反向传播时信号有合理的幅度**。
> 
> 如果全部权重初始化为 0：所有神经元输出完全一样，反向梯度全部相同，神经元永远学不出不同特征，网络失效。**绝对不能全部置 0**（偏置 bias 可以置 0）。

## 一、为什么不能权重全部设为 0

所有权重 w=0：

每一层所有神经元输出完全相等；反向传播每个神经元梯度完全一样；所有神经元更新后依旧一模一样，失去表达能力。

> ✅偏置 bias 一般可以初始化为 0，没问题。

## 二、常见初始化方法

### 1. 随机小常数初始化（老式，现在很少用）

从很小的均匀分布 U(−ϵ,+ϵ) 采样权重。

缺点：网络加深之后，信号会越来越大或者越来越小，深层网络不稳定。

---

### 2. Xavier 初始化（Glorot 初始化）⭐适合 sigmoid /tanh

适用激活：**sigmoid、tanh**（饱和型激活）

目标：保证**前向传播每一层输出方差尽量不变；反向传播梯度方差尽量不变**。

#### Xavier‑Uniform（均匀分布）

权重采样区间：

w∼U[−nin​+nout​6​​,+nin​+nout​6​​]

nin​：输入神经元数量；nout​：输出神经元数量

#### Xavier‑Normal（正态分布）

w∼N(0,nin​+nout​2​​)

> PyTorch：`nn.init.xavier_uniform_()` / `nn.init.xavier_normal_()`

> 注意：**Xavier 不适合 ReLU！** ReLU 会把一半神经元置 0，会破坏方差，信号会衰减。

---

### 3. He 初始化（Kaiming 初始化）⭐**ReLU / LeakyReLU 首选，最常用**

专门为 ReLU 系列激活函数设计（CNN、MLP 绝大多数用这个）。

ReLU 会截断负数，输出方差会减半，He 初始化把这个效应补偿掉。

#### Kaiming‑Normal（正态，最常用）

w∼N(0,nin​2​​)

#### Kaiming‑Uniform（均匀）

w∼U[−nin​6​​,+nin​6​​]

PyTorch 接口：

`nn.init.kaiming_normal_()`、`nn.init.kaiming_uniform_()`

> ✔️Conv2d、Linear 层搭配 ReLU，**默认用 Kaiming He 初始化**。

---

### 4. 常量初始化

- `nn.init.constant_(w, 0)`：权重全部置 0（**不推荐，会失效**）
- bias 偏置经常：`nn.init.constant_(b,0)`，偏置置 0 是常规操作。

### 5. 正交初始化 Orthogonal

适合 RNN/LSTM 循环网络！

循环网络的循环权重 Wh​ 如果初始化不好极易梯度爆炸 / 消失。

正交矩阵：矩阵乘以自身转置等于单位矩阵，可以保留梯度的范数。

python

```
nn.init.orthogonal_(w)
```

> RNN、LSTM 的循环权重强烈建议正交初始化。

### 6. 预训练权重（迁移学习）

不是随机初始化，直接加载别人训练好的权重。

比如 ResNet 加载 ImageNet 预训练参数，再微调。

## 三、PyTorch 内置层**默认初始化规则（很重要）**

1. `nn.Linear`：权重默认 **Kaiming 均匀分布**；bias 默认为 0
2. `nn.Conv2d`卷积层：权重默认 **Kaiming 均匀分布**；bias 默认为 0
3. `nn.LSTM / nn.RNN`：权重使用均匀分布；实践中很多人手动把循环权重改成正交初始化提升稳定性。
4. `nn.BatchNorm2d`：权重 γ 初始化为 1，偏置 β 初始化为 0。

> BN 层特殊：y^​=γ⋅σx−μ​+β，初始 γ=1,β=0，一开始等价于不做归一化。

## 四、怎么手动给网络做初始化（代码示例）

python

```
import torch
import torch.nn as nn

def init_weights(m):
    if isinstance(m, nn.Conv2d):
        # 卷积层+ReLU使用kaiming_normal
        nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')
        if m.bias is not None:
            nn.init.constant_(m.bias, 0)
    elif isinstance(m, nn.Linear):
        nn.init.kaiming_normal_(m.weight)
        nn.init.constant_(m.bias, 0)
    elif isinstance(m, nn.BatchNorm2d):
        nn.init.constant_(m.weight, 1)
        nn.init.constant_(m.bias, 0)

model = nn.Sequential(
    nn.Conv2d(3,16,3,padding=1),
    nn.ReLU(),
    nn.BatchNorm2d(16),
    nn.Flatten(),
    nn.Linear(16*32*32,10)
)
# 遍历所有模块，执行初始化
model.apply(init_weights)
```

## 五、怎么判断初始化好不好？

调试小技巧：

1. 打印每一层输出张量的均值、方差；理想状态均值接近 0，方差接近 1。
2. 如果输出全部趋近 0，说明初始化太小；
3. 如果输出全部 ±1 饱和（tanh 全部 ±1），说明权重太大。

## 六、快速选型记忆表

表格

|初始化|适用激活|典型使用场景|
|---|---|---|
|Xavier(Glorot)|sigmoid、tanh|老网络，很少现在用|
|He(Kaiming)|ReLU、LeakyReLU|CNN、MLP，**绝大多数场景**|
|Orthogonal|-|RNN、LSTM 循环权重|
|全部置 0|——|❌权重禁止，bias 可以置 0|

## 面试高频考点总结

1. 权重不能全部初始化为 0：神经元对称，无法学习不同特征；bias 可以为 0。
2. Xavier 针对 tanh/sigmoid；**He 初始化专门给 ReLU，CNN 最常用**。
3. RNN/LSTM 循环权重推荐正交初始化。
4. BN 层：γ=1，β=0。
5. PyTorch Conv2d、Linear 默认已经 Kaiming 初始化，一般不用自己写；复杂网络、RNN 建议手动初始化。

> 补充：初始化只是给网络一个好起点，**不能解决训练后期的梯度消失，只能解决训练刚开始的信号爆炸 / 消失**。训练后期梯度消失要靠残差连接、门控 (LSTM) 等结构。
