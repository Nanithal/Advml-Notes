# 含有未知参数的function
liner model可能无法模拟真实情况
这时可以引入多个个函数并且根据x范围来将这多个函数中的几个加起来模拟数据情况，可以理解为分段函数
即All piece wise Linear Curves=constant + sum of a set of functions。
piece wise 意思为分段线性
如果是曲线的时候，曲线业可以用piecewise Linear Curves来模拟（逼近），那么曲线就可以用多个函数联系加常数表达
函数一般用sigmoid函数(激活函数)(不是hard sigmoid函数)来模拟
$$\sigma(x) = c\frac{1}{1 + e^{-(wx+b)}}$$
调整b，w,c 来组成不同的激活函数从而组成各式合适的function(即用来拟合数据分布的函数)

# Define loss from training data

依旧真实值减去预测值，只不过参数为$\theta$而已，即$L(\theta)$

# Optimization
依旧梯度下降(gradient descent)
	1.初始随机选$\theta_0$
	2.每一个参数相对于$L$做微分(偏导)且结果放在向量g中，向量g叫做gradient(梯度)
	3.结合学习率来更新参数
	![[attachment/Pasted image 20260427193505.png|324]]
	上标代表这是第几次迭代
	4.循环直到gradien为0(实际中不存在)或者不想做了
	5.实战中，是先将数据分成多个batch(均分?)，拿出一个batch得到$L_1$来update$\theta$，随后下一个batch再得到$L_2(\theta_1)$并update.....,即用前一步结果继续迭代。所有的batch都被使用过一次叫做epoch。
	![[attachment/Pasted image 20260427194907.png|369]]
	 注：人为规定的参数叫做Hyperparameter(超参数)

# 激活函数

如果把神经网络比作一个大脑，神经元就是其中的细胞。激活函数的作用就是决定一个神经元接收到的信号是否足够重要，以至于需要向后面的神经元传递信息。
## 1. 核心作用：引入非线性
这是激活函数最核心的价值。
- **没有激活函数：** 无论你的神经网络有多少层，它本质上都只是在做简单的加法和乘法（线性变换）。即便有一千层，最终也只能表达简单的直线关系。
- **有了激活函数：** 它给网络注入了“弯曲”的能力。这使得神经网络可以拟合极其复杂的函数，比如识别图片里的猫、翻译一段复杂的文字，或者预测股票走势。
## 2. 它在神经元里做了什么？

在一个神经元中，计算分为两步：
1. **求和：** 将输入数据乘以权重并相加（$z = w \cdot x + b$）。
2. **激活：** 将这个求和结果 $z$ 丢进**激活函数** $f(z)$。

# Neuron(神经元/神经细胞)

sigmoid、ReLU...都是神经元，众多的Neuron叫做NeuraL Network(神经元网络)，这些都是从人脑的相关概念引入的，模型则是在模拟人脑。其中，每一排Neuron叫做一个layer(层)。层包括输入层、隐藏层和输出层。隐藏层做的事就是处理输入并给出输出，对外界来说就像黑盒一样，因此叫做隐藏层。
# Rectified Linear Unit（ReLU）与hard sigmoid
中文：**修正线性单元**

$$f(x) = \max(0, x)$$
如果输入是正数，原样输出；是负数，直接变成0
两个ReLU叠起来就可以变成hard sigmoid（两个L型凑成一个S型）
![[attachment/Pasted image 20260427201630.png|346]]
传统的激活函数（如 Sigmoid 或 Tanh）包含复杂的指数运算 $e^x$，这在计算时非常耗时。
- **ReLU** 是对线性函数的一种“修正”，它在 $0$ 处折断。
- **Hard Sigmoid** 是对 S 型曲线的“直线化”模拟。
它们都抛弃了平滑的曲线，转而使用**直线段**拼接。这种做法让计算机只需要做“大于、小于”的逻辑判断和简单的乘加运算，速度极快。
