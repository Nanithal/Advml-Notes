# CornerSearch - 稀疏对抗攻击

**CornerSearch** 是由 Francesco Croce 和 Matthias Hein（同时也是著名评估基准 **AutoAttack** 的作者）在 2019 年提出的一种针对 **$L_0$ 范数约束**的黑色/灰色方框对抗攻击算法（通常属于 Query-based 或近似无梯度攻击）。

针对 $L_0$ 范数攻击，传统算法如 JSMA、C&W-$L_0$ 等依赖模型梯度，且容易陷入局部最优；而纯无导数方法（如基于差分进化的 One Pixel Attack）随着图像尺寸增大（如 $224 \times 224$），搜索空间呈指数爆炸，查询效率极低。

**CornerSearch** 的核心精髓在于：**将极其复杂的连续/离散混合优化问题，巧妙地简化为沿着超立方体边界角点（Corners）的贪心搜索**，从而在大尺寸图像和多像素 $L_0$ 攻击中实现了高成功率与低查询次数的平衡。

下面将从 **设计动机 $\rightarrow$ 数学原理 $\rightarrow$ 算法核心步骤 $\rightarrow$ 算法优势与应用** 为你全面拆解 CornerSearch。

### 一、 核心动机：为什么叫“Corner”（角点）Search？

在图像处理中，每个像素的 RGB 通道数值通常被归一化在 $[0, 1]$ 区间内。所有可能图像构成的高维空间就是一个**超立方体（Hypercube） $[0, 1]^d$**。

1. **什么是角点（Corners）？**
    
    超立方体的“角点”，指的是所有通道像素值都取在极限边界 $\{0, 1\}$ 上的点（即极黑 $0$ 或极白 $1$）。
    
2. **直观洞察（Intuition）**：
    
    作者观察到，在进行 $L_0$ 攻击时，将选中的像素直接推到它的极值边界（即黑/白两个极端角点），往往能给神经网络的特征激活带来最大幅度的扰动，从而最容易触发模型的分类错误。
    
3. **空间简化**：
    
    对于某个像素 $i$，原先的搜索空间是连续区间 $[0, 1]$（有无穷多个取值可能）；CornerSearch 将其简化为**只测试 2 个离散点**——$0$ 和 $1$（如果图像包含 3 个 RGB 通道，则是对应通道的极值）。
    

### 二、 数学表述与攻击目标

假设原始图像为 $x \in [0, 1]^d$，分类模型为 $f(x)$，正确标签为 $y$。

$L_0$ 攻击的目标是找到一个扰动 $\delta$，使得：

$$\min \Vert{}\delta\Vert{}_0 \quad \text{s.t.} \quad f(x + \delta) \neq y \quad \text{且} \quad x + \delta \in [0, 1]^d$$

其中 $\Vert{}\delta\Vert{}_0$ 表示被修改的像素个数。

对于每个候选修改像素 $i$，CornerSearch 考察将其修改为角点值 $c_i \in \{0, 1\}$ 所产生的决策改动。

### 三、 CornerSearch 算法详细流程拆解

CornerSearch 的执行过程主要分为两个阶段：**像素敏感度评估（Pixel Prioritization）** 和 **贪心迭代选择（Greedy Selection）**。

#### 阶段 1：像素敏感度排序（找到最“脆弱”的像素）

面对一张含有几万甚至几十万像素的图像，不能盲目随机搜索。首先需要对所有像素进行一次快速的“敏感度打分”：

1. **逐像素尝试角点修改**：
    
    对于图像中的每一个像素 $i$（或者像素块）：
    
    - 分别尝试将其修改为极值 $0$ 和 $1$；
        
    - 将修改后的图像送入模型，观察模型输出概率/ Logits 的变化。
        
2. **计算目标损失增量**：
    
    评估该修改对降低正确类别 $y$ 的置信度（或增加错误类别的置信度）贡献有多大。
    
3. **生成候选像素优先队列**：
    
    按照对模型决策影响程度从大到小，对所有像素进行排序，得到一个优先级列表 $\mathcal{I} = [p_1, p_2, \dots, p_d]$。
    
    - _注_：这一步极大缩小了搜索范围，后续只需要按顺序测试前 $k$ 个最敏感的像素。
        

#### 阶段 2：贪心搜索与多像素组合（Corner Search）

在确定了像素敏感度顺序后，算法开始寻找最小的像素集合来翻转分类：

1. **单像素攻击尝试（$L_0 = 1$）**：
    
    - 遍历优先级列表中靠前的像素；
        
    - 如果仅将某一个像素修改为对应的角点值就能让 $f(x') \neq y$，则攻击成功，直接输出，此时 $\Vert{}\delta\Vert{}_0 = 1$。
        
2. **多像素累加攻击（$L_0 = k$）**：
    
    - 如果单像素无法成功，算法进入贪心组合阶段；
        
    - **锁定与搜索**：保留当前对模型破坏力最大的像素修改，然后从优先列表中选择下一个像素，测试其角点结合后的效果；
        
    - **动态剪枝**：如果在组合过程中，加入某个像素没有带来损失函数的改善，算法会跳过该像素，继续尝试列表中的下一个；
        
    - **循环终止**：直到模型分类彻底翻转（攻击成功），或者达到设定的最大修改像素上限 $K_{\text{max}}$。
        

### 四、 CornerSearch 的主要优势

1. **无需模型梯度信息（黑盒/灰盒友好）**：
    
    CornerSearch 只需要模型的输出概率（或 Logits），不需要反向传播求梯度，因此对不可导模型、带梯度掩蔽（Gradient Masking）防御的模型依然有效。
    
2. **查询效率高（Query-Efficient）**：
    
    相比于随机漫步或演化算法，CornerSearch 通过**确定性的“角点评估 + 敏感度排序”**，大幅减少了对模型进行 Query 的次数。
    
3. **高攻击成功率**：
    
    在 CIFAR-10、ImageNet 等标准数据集上，CornerSearch 可以在仅修改极少数像素（例如 $L_0 \le 10$）的情况下，达到极高的攻击成功率。
    
4. **作为鲁棒性评估的强基准**：
    
    在评估模型对 $L_0$ 稀疏噪声的鲁棒性时，Croce 等人常将 CornerSearch 作为一种可靠的底层攻击手段（例如在 AutoAttack 的扩展或评估体系中）。
    

### 五、 总结与对比

|**维度**|**One Pixel Attack (DE)**|**JSMA**|**CornerSearch**|
|---|---|---|---|
|**范数限制**|$L_0$（通常 $L_0=1$）|$L_0$|**$L_0$（支持 1 到多个像素）**|
|**搜索空间**|连续空间（基于差分进化）|导数显著图|**超立方体边界角点 $\{0, 1\}$**|
|**依赖梯度**|否（纯黑盒）|是（白盒，需雅可比矩阵）|**否（仅需输出 Logits/概率）**|
|**大图扩展性**|差（在大图上极难收敛）|一般|**优（通过敏感度排序高效筛选）**|
