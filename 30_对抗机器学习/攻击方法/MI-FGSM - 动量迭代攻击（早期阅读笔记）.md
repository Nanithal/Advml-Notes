# MI-FGSM - 动量迭代攻击（早期阅读笔记）

文章链接：[https://openaccess.thecvf.com/content_cvpr_2018/papers/Dong_Boosting_Adversarial_Attacks_CVPR_2018_paper.pdf]
# 对抗攻击简介

现有的对抗攻击方法只能以较低的成功率欺骗黑箱模型，由此提出一类基于动量的迭代算法以增强对抗攻击，即动量迭代快速梯度符号表示法。

# 现有对抗攻击方法的不足

现有的攻击方法在攻击黑箱模型时表现出低效，尤其是对于那些具有防御机制的模型。这一事实在很大程度上归因于攻击能力与可转移性之间的权衡。本方法考虑如何在不知道其架构和参数的情况下有效攻击黑箱模型，并进一步在不进行查询的情况下进行攻击。

# MI-FGSM与其他方法的不同

动量方法在损失函数的梯度方向上累积速度向量，以稳定更新方向并逃离不良局部极大值。这使得通过动量迭代方法生成的对抗样本在白盒和黑盒攻击中具有更高的成功率。所提出的方法缓解了白盒攻击与可转移性之间的权衡，并且比一步法和普通迭代方法更强大。

# 文章结论

- 介绍了一类称为动量迭代梯度方法的攻击算法，在每次迭代中累积损失函数的梯度，以稳定优化并逃离不良局部极大值。
-  研究了几种集成方法，以同时攻击多个模型，这展示了通过保持高成功率的攻击而具有强大的可转移能力。 
- •首次表明，通过具有强大防御能力的集成对抗训练获得的模型也容易受到黑箱攻击。

# 背景知识

对于一个分类器，对抗攻击的目标是寻找一个在$x$附近的示例$x ∗$，但被分类器错误分类。
其中，对抗示例分为两类——非目标型和目标型。非目标型不改变标签，目标性输出特定标签。


# 现有的生成对抗攻击方式
- 一步梯度基础方法
例如快速梯度符号方法，通过最大化损失函数 $(x ∗ , y)$ 来找到对抗样本$x ∗$，其中 J 通常是交叉熵损失。FGSM 生成对抗样本以满足 $L∞$ 范数界限 $\|x^* - x\|_{\infty} \leq \epsilon \text{ as}$。
- 迭代方法
迭代方法以小步长 $α$ 多次迭代地应用快速梯度。迭代方法在可转移性较差的情况下，比单步方法更强大，成为更强的白盒对手。
- 基于优化的方法
该方法直接优化真实样本与对抗样本之间的距离，以使对抗样本的误分类。

| 方法           | 白盒攻击成功率 | 黑盒迁移性 |
| ------------ | ------- | ----- |
| 一步方法(FGSM)   | 一般      | 较好    |
| 迭代方法(I-FGSM) | 很高      | 较差    |
| 优化方法(L-BFGS) | 很高      | 较差    |
问题：白盒攻击强的，黑盒迁移性差；迁移性好的，白盒攻击弱。
# 提高模型防御力方法

对抗训练是提高深度神经网络（DNN）鲁棒性最广泛研究的方法。通过将对抗样本注入训练过程，对抗训练的模型学习抵抗损失函数梯度方向的扰动。然而，由于对抗样本的生成与正在训练的参数之间的耦合，它们并未赋予对黑箱攻击的鲁棒性。集成对抗训练通过不仅使用正在训练的模型生成的对抗样本，还使用其他保留模型生成的对抗样本来增强训练数据。因此，集成对抗训练的模型对一步攻击和黑箱攻击具有鲁棒性。

# MI-FGSM算法

核心思想：在迭代攻击中引入**动量**，让更新方向更稳定，避免陷入“局部最优”。

## 算法步骤

1. 初始化
- 扰动大小 $\varepsilon$ ，迭代次数 $T$ ,步长$\alpha= \varepsilon / T$
- 动量向量 $g_0 = 0$,对抗样本$x_0 * =x$
2. 每次迭代
- 计算当前样本的梯度    $\nabla J(x_t^*, y)$
- 更新动量：
		$g_{t+1} = \mu \cdot g_t + \frac{\nabla J(x_t^*, y)}{\left\| \nabla J(x_t^*, y) \right\|_1}$
- 更新对抗样本
	 $x_{t+1}^* = x_t^* + \alpha \cdot \mathrm{sign}(g_{t+1})$
- 
3. 返回最终对抗样本 $x_T^*$

## 关键点
- $\mu$是动量衰减因子（通常设为1.0）
- 梯度归一化防止不同迭代的梯度制度差异过大
- 动量让更新方向更一致，避免“过拟合”当前模型
首先说明如何将动量集成到迭代的$FGSM$中，从而产生动量迭代快速梯度符号方法（$MI-FGSM$），以生成满足$L∞$范数限制的非目标攻击的对抗样本。然后，提出几种有效攻击模型集的方法。最后，将$MI-FGSM$扩展到$L2$范数约束和目标攻击，产生一类广泛的攻击方法。

## 动量迭代快速梯度符号方法

动量方法是一种通过在损失函数的梯度方向上累积速度向量来加速梯度下降算法的技术。因此，基于动量的方法在增加迭代次数时保持了对抗样本的可转移性，同时对像迭代FGSM这样的白盒模型构成了强有力的对抗。它缓解了攻击能力与可转移性之间的权衡，展示了强大的黑盒攻击能力。


# MI-FGSM相关参数

### 衰减因子 $u$
当$u=0$时，将变成普通的迭代方法，以此衰减因子需要有适当的值。

### 迭代次数
当增加迭代次数时，$I-FGSM$对黑箱模型的成功率逐渐下降，而$MI-FGSM$的成功率保持在较高的水平。得到结论：即通过迭代方法生成的对抗样本容易过拟合白箱模型，并且不太可能在模型之间迁移。但基于动量的迭代方法有助于缓解白箱攻击与可迁移性之间的权衡，从而同时展示出对白箱和黑箱模型的强攻击能力。

# 如何攻击多个模型

为了增强黑盒攻击能力，可以同时攻击多个模型：
-  **集成方式** :融合多个模型的**logits**（分类前的输出）
- 然后基于融合后的logits计算损失和梯度
		$I(x) = \sum_{k} w_k \cdot I_k(x)$
实验证明 ：融合 logits比融合预测概率或损失更好

在这一部分，提议攻击多个其对数激活值融合在一起的模型，称作这种方法为对数集成。通过对数融合的模型集成汇聚了所有模型的细节输出，这些输出的脆弱性可以很容易被发现。

# 为什么MI-FGSM更好
- 更新方向跟稳定（余弦相似度高）
- 避免陷入“局部最优点”，这些点通常不可迁移
- 对抗样本的扰动更大（$L2$范数更大），有助于迁移
# 扩展

动量迭代方法可以很容易地推广到其他攻击设置。通过用所有先前步骤的累积梯度替换当前梯度，任何迭代方法都可以扩展为其动量变体。
