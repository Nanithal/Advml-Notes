# 对抗攻击 - 开创性工作阅读笔记

[文档链接](https://arxiv.org/pdf/1412.6572 
)
## 背景
当对数据集施加**小但故意**的错误后，模型（神经网络等）往往可能会出现以**高置信度输出错误判断**的情况。那么对抗样本便可以暴露出模型的算法盲点。因此我们可以认为人为地制造**对抗样本**，即生成让模型以高置信度判断错误的样本。
## 原因
高维空间的**线性行为**（不是非线性）会导致对抗样本。转向RBF网洛等非**线性模型族**可以降低模型对对抗样本的脆弱性
在计算中：$w^T$x  ,
加扰动后：$x'=x+\eta$
那么：$w^Tx'=w^Tx+w^T\eta$ ，虽然每一维改动很小，但维度多，造成巨大影响。

## RBF网络
RBF网络（Radial Basis Function Network，径向基函数网络）：通过使用**径向基函数**（通常是高斯函数）作为激活函数来将输入映射到高维空间，从而提高模型的非线性表达能力。包括三个层
- 输入层
- 隐藏层
- 输出层
当RBF网络面对对抗样本时，它的置信度较低，即使错误率高。
RBF网络更抗攻击，因为它的非线性更强且不会在远离数据的地方乱自信
## 对对抗样本的线性解释

在问题中，单个特征的精度输入是有限的，往往会丢弃一些信息。那么当对抗样本$\tilde{x}=x+\eta$时，如果扰动$\eta$的每个元素都小于特征的精度，那么则会被分类器分成相同的类别。如果输入具有足够的维度，简单的线性模型也可以产生对抗样本。那么足够线性的模型、神经网络，会无法抵抗对抗扰动、损害神经网络。
## 生成对抗样本的方法

### 快速梯度表示法（重要算法）
在这个方法里面，需要做的事是改变输入$x$来s最大化损失
算法公式：$x' = x + \epsilon \cdot \mathrm{sign}\left( \nabla_x J(\theta, x, y) \right)$
1. 计算损失函数对输入的梯度
            $\nabla_x J(\theta, x, y)$
2. 取符号（只要方向，不要大小）
$$ \text{sign}(x) = \begin{cases} 1 & x > 0 \\ 0 & x = 0 \\ -1 & x < 0 \end{cases} $$
依据正负号来判断是增加还是减少
3. 乘一个很小的$\varepsilon$(扰动强度)
4. 加到原图上
即往最容易让模型出错的方向推一小步

上述两种方法在加速对抗训练或仅仅分析训练网络方面也很有用。

## 对抗样本的重要性质
1. 可迁移性
在A模型上生成的攻击，可以骗过B模型（本质上都是线性）
2. 普遍存在
高维空间里，大多数点都是“对抗点”
3. 不依赖具体位置，只看方向
关键是扰动方向，而不是具体数据点
# 其他

		对抗样本在不同的干净样本中具有普遍性
		对抗样本可以导致正则化，甚至比dropout还要强烈
		易于优化的模型也易于扰动
		线性模型缺乏抵抗对抗扰动的能力；只有具有隐藏层的结构（适用通用逼近定理）应该被训练以抵抗对抗扰动。
		RBF网络对对抗样本具有抵抗力。
		集成模型对对抗样本不具抵抗力。
			浅层线性模型对垃圾样本不具有抵抗力
# 快速梯度符号攻击

思路：使用关于输入数据的损失梯度，然后调整输入数据以最大化损失，而不是最小化损失
