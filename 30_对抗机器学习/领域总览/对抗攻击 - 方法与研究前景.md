# 对抗攻击 - 方法与研究前景

![[attachment/Pasted image 20261006133314.png|459]]
可以。你这张图其实不是一个严格的“攻击分类体系”，而是把**不同攻击对象、攻击目标、攻击场景、攻击方法**混在了一起。

比如：

- **Gradient-based Attack**：按“怎么攻击”分类
- **Targeted Attack**：按“攻击目标”分类
- **Black-box Attack**：按“攻击者知道多少”分类
- **VLM Attack**：按“攻击什么模型”分类
- **Universal Attack**：按“扰动是否针对单个样本”分类
- **Backdoor Attack**：按“攻击发生在训练阶段/模型植入后门”分类

所以它们之间是可以**交叉组合**的。比如：

> Black-box + Targeted + VLM + Transfer-based Attack

完全可以同时成立。

目前对抗机器学习的研究也已经从传统图像分类，扩展到了 VLM、MLLM、LLM Agent、扩散模型、多模态系统等。NIST 的对抗机器学习分类也明确从攻击阶段、攻击目标、攻击者能力等多个维度来组织攻击。

下面我按照你图里的顺序给你讲。

# 一、先建立一个总框架

你可以先把这些攻击放进下面这个框架：

```
                    对抗攻击
                       │
       ┌───────────────┼────────────────┐
       │               │                │
    攻击对象         攻击方式          攻击目标
       │               │                │
   CNN / ViT        Gradient         Targeted
   VLM / LLM        Optimization      Untargeted
   Agent            Transfer          Universal
   GNN              Query             ...
   Diffusion        Input Transform
                    ...
```

再加两个重要维度：

```
攻击者掌握的信息
       │
       ├── White-box
       ├── Gray-box
       └── Black-box

攻击发生阶段
       │
       ├── Training-time
       │      ├── Poisoning
       │      └── Backdoor
       │
       └── Inference-time
              ├── Evasion
              ├── Adversarial Example
              └── Prompt Injection
```

因此，**不要把图里的 30 个东西理解成 30 个完全独立的研究方向。**

# 二、逐个解释

## 1. Feature Attack —— 特征攻击

核心思想：

> **不一定直接攻击最终分类结果，而是攻击模型内部学到的 feature representation。**

正常情况下：

```
图片
 ↓
CNN / ViT
 ↓
Feature
 ↓
Classifier
 ↓
类别
```

Feature Attack：

```
原图 x
 ↓
模型
 ↓
正常 Feature z

对 x 添加扰动
 ↓
模型
 ↓
Feature z'
       ↓
让 z' 偏离原来的语义结构
```

例如希望：

```
猫图片
 ↓
正常 feature → “猫”

攻击后
 ↓
feature → 更接近“狗”
```

或者直接让不同模型之间的特征距离发生变化。

### 研究价值：★★★★★

这个方向和你之前关注的**“多粒度特征对齐、迁移攻击”**非常接近。

尤其可以研究：

> 局部特征 → 中层语义 → 高层语义 → 跨模型特征空间

这其实是非常好的研究切入点。

---

# 2. Ensemble Attack —— 集成攻击

假设有：

```
Model A
Model B
Model C
```

传统攻击：

```
攻击 Model A
```

集成攻击：

```
同时考虑 A+B+C

      ↓
构造一个攻击样本

      ↓
A、B、C 都容易被攻击
```

数学上可以简单理解成：

$$
L_{ens}(x)=\sum_i w_iL_i(x)
$$

然后：

$$
x'=x+\delta
$$

让多个模型的 loss 同时变差。

### 为什么重要？

因为这和**迁移攻击**关系非常密切。

你真正想解决的是：

> 我不知道目标模型参数，但我能不能在代理模型上生成一个攻击样本，然后迁移到目标模型？

这就是目前非常经典的研究路线。

### 前景：★★★★☆

但“简单 ensemble”已经比较成熟。

真正值得研究的是：

> **怎么进行更智能的模型选择、特征层集成、梯度冲突消除、语义层对齐。**

---

# 3. Backdoor Attack —— 后门攻击

这个和普通 adversarial example 很不一样。

正常训练：

```
猫 → 猫
狗 → 狗
```

攻击者在训练数据中加入：

```
带特殊 trigger 的猫 → 狗
```

例如：

```
猫 + trigger
      ↓
     狗
```

模型训练之后：

```
普通猫 → 猫

带 trigger 的猫 → 狗
```

也就是说：

> 模型平时看起来完全正常，但遇到特定 trigger 就执行攻击者预设行为。

### 前景：★★★★★

非常有研究价值。

特别是：

- LLM Backdoor
- VLM Backdoor
- Multimodal Backdoor
- LoRA Backdoor
- Agent Backdoor

现在研究非常活跃。

NIST 也把 backdoor/trojan attack 作为重要的 AML 威胁类型。

---

# 4. VLM / VLPM Attack

VLM：

> Vision-Language Model

例如：

```
图片 + 问题
      ↓
VLM
      ↓
回答
```

攻击者可以攻击：

### 图像

```
正常图片
 ↓
对抗扰动
 ↓
VLM理解错误
```

### 文本

```
正常 Prompt
 ↓
恶意文本
 ↓
VLM输出错误
```

### 跨模态

```
Image
  +
Text
  ↓
攻击两种模态之间的关系
```

这是现在非常值得关注的方向。2025–2026 年已经出现多篇专门针对多模态模型 adversarial robustness 的综述，研究重点包括跨模态攻击、表示空间攻击以及模型融合机制等。

### 前景：★★★★★

**非常高。**

如果你现在准备选一个新的研究方向，我会把：

> **多模态模型 + 对抗攻击**

放在很靠前的位置。

# 5. Watermark Attack —— 水印攻击

例如一个模型/图片里面有：

```
Watermark
   ↓
用于证明 AI 生成
```

攻击者想：

> 把水印去掉，但尽量不影响原始内容。

比如：

```
AI生成图片
 ↓
带水印

攻击
 ↓
去水印
```

或者攻击模型水印，让模型的 ownership verification 失效。

### 前景：★★★☆

有研究价值，但属于比较专门的方向。

如果你的目标是：

> 对抗学习 + 大模型

我不会把它作为第一选择。

---

# 6. Imperceptible Attack —— 不可感知攻击

目标：

> 人眼看不出来，但是模型已经被攻击。

例如：

```
原图：

🐱

攻击后：

🐱

人：
“还是猫啊？”

模型：
“不是猫”
```

数学上通常限制：

$$
\|\delta\|_p < \epsilon
$$

也就是：

```
扰动很小
```

但是：

```
模型输出发生巨大变化
```

经典的：

- FGSM
- PGD
- C&W

都属于相关思想。

### 前景：★★★☆

基础非常重要，但单纯研究“更小的扰动”已经比较卷。

如果和：

> feature alignment / semantic alignment / transferability

结合起来，价值会明显提高。

---

# 7. Multi-Label Attack —— 多标签攻击

普通分类：

```
图片 → 猫
```

Multi-label：

```
图片 → 猫、汽车、树、房子
```

攻击：

```
原始：
猫 + 狗 + 汽车

攻击：
猫 + 汽车

或者：
猫 → 不再识别
```

难点在于：

> 多个 label 之间存在相关性。

因此攻击一个 label 可能影响其他 label。

### 前景：★★★☆

有研究价值，但是应用范围比普通 classification attack 小。

---

# 8. Targeted Attack —— 定向攻击

这个非常重要。

普通：

$$
f(x')\neq y
$$

只要分类错误就行。

Targeted：

$$
f(x')=y_{target}
$$

比如：

```
原图：猫

攻击目标：飞机

攻击：

猫 → 飞机
```

所以：

```
Untargeted
    ↓
“让它错”

Targeted
    ↓
“让它错成我指定的类别”
```

### 前景：★★★★☆

尤其适合：

- Targeted Transfer Attack
- Targeted VLM Attack
- Targeted Black-box Attack
- Targeted Semantic Attack

---

# 9. Graph Attack —— 图攻击

攻击对象不是图片，而是：

```
Graph
```

例如社交网络：

```
A —— B
|    |
C —— D
```

攻击者可能：

- 修改节点特征
- 添加节点
- 删除节点
- 修改边
- 注入恶意节点

最终：

```
G
 ↓
G'
 ↓
GNN
 ↓
错误预测
```

例如：

> 修改少量边，让 GNN 错误判断某个节点类别。

### 前景：★★★★☆

如果做：

> GNN + Security

挺不错。

但是和你目前的视觉/迁移对抗学习路线不太一致。

# 10. Face Attack —— 人脸攻击

攻击：

```
人脸图片
 ↓
对抗扰动
 ↓
Face Recognition
 ↓
错误身份
```

例如：

```
A的脸
 ↓
攻击
 ↓
系统认为是B
```

还可以攻击：

- Face Recognition
- Face Verification
- Face Detection
- Face Attribute Recognition

### 前景：★★★☆

应用价值很强，但是研究相对成熟。

如果做：

> Physical Face Attack

或者：

> Face + VLM

会更有意思。

# 11. Universal Attack —— 通用攻击

这是一个非常漂亮的概念。

普通攻击：

```
x1 → δ1
x2 → δ2
x3 → δ3
```

每张图片一个扰动。

Universal：

```
所有图片
   ↓
同一个 δ
   ↓
攻击很多图片
```

即：

$$
f(x+\delta)\neq f(x)
$$

对大量 $x$ 都成立。

### 为什么厉害？

因为：

> 一个扰动可以攻击很多样本。

### 前景：★★★★☆

尤其可以研究：

> Universal + Transfer

> Universal + VLM

> Universal + Physical World

> Universal + Diffusion

---

# 12. Cross-Domain Attack —— 跨域攻击

例如：

```
Source Domain
      ↓
攻击
      ↓
Target Domain
```

比如：

```
训练：
清晰照片

攻击：
素描 / 卡通 / 夜间 / 雾天
```

或者：

```
ImageNet
   ↓
生成攻击
   ↓
医学图像
```

核心问题：

> **攻击能不能跨越 domain shift？**

### 前景：★★★★★

这个方向非常适合你的“迁移攻击”。

因为迁移攻击本质上就涉及：

> source → target

而 Cross-domain 更进一步：

> source distribution → different target distribution

# 13. SAM Attack

这里的 SAM 一般指：

> Segment Anything Model

也就是分割基础模型。

攻击：

```
图片
 ↓
SAM
 ↓
Mask
```

攻击者修改输入：

```
图片 + δ
 ↓
SAM
 ↓
错误 Mask
```

例如：

```
真实：
████
████

攻击后：
██
██
```

### 前景：★★★★☆

如果进一步做：

> Foundation Model + Adversarial Attack

还是不错的。

# 14. LLM Attack

攻击：

```
LLM
```

主要包括：

- Prompt Injection
- Jailbreak
- Adversarial Prompt
- Data Poisoning
- Backdoor
- Model Extraction
- Training-time attacks

例如：

```
System Instruction
       ↓
User Prompt
       ↓
恶意 Prompt
       ↓
LLM
       ↓
错误行为
```

### 前景：★★★★★

但是：

> **LLM attack 已经非常火。**

所以竞争也非常激烈。

真正有研究价值的不是：

> “我又找了一个 jailbreak prompt”

而是：

> **解释为什么攻击成功 + 建立统一攻击框架 + 提出可泛化攻击/防御。**

# 15. Agent Attack

这是我认为你图里面**非常值得关注的方向之一**。

LLM：

```
User
 ↓
LLM
 ↓
Answer
```

Agent：

```
User
 ↓
LLM Agent
 ↓
Planning
 ↓
Tool
 ↓
Web / Code / Database
 ↓
Action
```

所以攻击面大很多。

例如：

```
恶意网页
 ↓
Agent读取
 ↓
Prompt Injection
 ↓
Agent被欺骗
 ↓
执行错误操作
```

这和传统 adversarial example 已经很不一样了。

目前 agent security 已经成为一个快速发展的研究方向，研究重点包括 prompt injection、multimodal attack、runtime monitoring、red teaming、多智能体安全等。

### 前景：★★★★★

甚至可以说：

> **未来几年很值得关注。**

---

# 16. Black-box Attack

攻击者不知道模型：

```
参数 ❌
结构 ❌
梯度 ❌
```

只能：

```
输入 x
 ↓
API
 ↓
输出
```

然后根据输出不断查询。

主要两类：

### Query-based

利用模型返回的：

```
概率
score
logits
```

不断优化攻击。

### Decision-based

甚至只知道：

```
猫
狗
```

这种最终决策。

### 前景：★★★★★

非常重要。

因为真实世界 API 基本都是：

```
Black-box
```

所以：

> **Black-box + Transfer**

是很有实际价值的。

---

# 17. LoRA Attack

LoRA 是参数高效微调技术。

正常：

```
Base Model
    +
LoRA Adapter
    ↓
Fine-tuned Model
```

攻击可以针对：

```
LoRA Adapter
```

例如：

> 恶意 LoRA

加载之后：

```
原始模型正常
      ↓
加载 LoRA
      ↓
模型产生恶意行为
```

也可以研究：

- LoRA poisoning
- LoRA backdoor
- LoRA adversarial robustness
- malicious adapters

### 前景：★★★★★

因为现在大量开源模型使用：

> PEFT / LoRA / Adapter

所以安全问题很现实。

---

# 18. Input Transformation-based Attack

不直接优化像素：

```
x + δ
```

而是通过：

```
Resize
Crop
Rotate
Translate
JPEG
Blur
Color transformation
```

等输入变换。

核心思想：

> 找到对各种 transformation 都有效的攻击。

例如：

```
x
 ↓
攻击
 ↓
resize
 ↓
模型
```

### 前景：★★★★☆

特别适合：

> Physical-world attack

因为现实环境天然存在：

```
旋转
缩放
光照
视角
压缩
```

# 19. Gradient-based Attack

这是你必须掌握的基础。

知道模型：

```
f(x;θ)
```

就可以计算：

$$
\nabla_x L(x,y)
$$

然后沿着让 loss 增大的方向修改：

$$
x'=x+\epsilon sign(\nabla_xL)
$$

这就是 FGSM 的基本思想。

PGD 则是：

```
攻击一步
 ↓
投影
 ↓
再攻击
 ↓
投影
 ↓
……
```

### 前景：★★★☆

**作为基础非常重要。**

但：

> 单纯“改进 FGSM/PGD”

现在比较难做出很强的新意。

---

# 20. Unrestricted Attack

传统攻击：

$$
\|\delta\|_p\leq\epsilon
$$

限制：

```
扰动必须很小
```

Unrestricted Attack 不一定要求：

```
L∞很小
```

而是要求：

> **攻击结果在人类语义上仍然合理。**

比如：

```
原图：
一只狗

攻击：
另一张看起来完全正常的狗图片
```

但模型：

```
认为是猫
```

所以从：

> pixel similarity

转向：

> semantic similarity

### 前景：★★★★☆

我认为这个方向比单纯追求 $L_p$ 更值得研究。

---

# 21. Diffusion Attack

利用：

> Diffusion Model

产生攻击样本。

例如：

```
原始图片
 ↓
Diffusion
 ↓
生成/修改
 ↓
Adversarial Image
```

优势：

传统：

```
像素级扰动
```

Diffusion：

```
生成语义级攻击
```

所以可能做到：

> 人看起来很自然，但模型判断发生巨大变化。

扩散模型本身已经成为 adversarial research 的一个重要新攻击面，近期综述也把它与 gradient-based、transfer、black-box、universal 等攻击一起纳入讨论。

### 前景：★★★★★

很值得关注。

---

# 22. Optimization-based Attack

把攻击直接写成优化问题：

$$
\min_\delta D(x,x+\delta)+\lambda L(x+\delta,y_t)
$$

也就是：

```
一方面：
扰动尽可能小

另一方面：
攻击效果尽可能强
```

然后用：

- Gradient Descent
- Adam
- C&W
- L-BFGS
- Evolutionary Algorithm
- 等

求解。

### 前景：★★★★☆

它更像：

> **攻击方法论**

而不是一个具体攻击对象。

---

# 23. Model Alignment-based Attack

这个我建议你重点看。

核心思想：

> 不只考虑模型输出，而是研究不同模型之间的 feature / representation alignment。

例如：

```
Model A feature
        ↕
Model B feature
        ↕
Model C feature
```

攻击时：

```
让源模型和目标模型的表示关系发生变化
```

或者：

> 利用不同模型之间共享的 representation structure。

这和：

> **Transfer Attack**

有非常强的联系。

### 前景：★★★★★

**非常适合你。**

尤其是你之前提到的：

> 多粒度特征对齐的迁移对抗攻击

这条线可以继续深化成：

```
Low-level feature
      ↓
Mid-level feature
      ↓
High-level semantic feature
      ↓
Cross-model alignment
      ↓
Transfer attack
```

这个逻辑是非常完整的。

---

# 24. Sparse Attack —— 稀疏攻击

普通攻击：

```
很多像素都修改一点
```

Sparse Attack：

```
只修改极少几个像素
```

例如：

```
原图：
██████████
██████████
██████████

攻击：
只修改几个位置
```

数学上追求：

$$
\|\delta\|_0
$$

尽可能小。

### 前景：★★★★☆

经典但仍然有研究空间。

尤其：

> Sparse + Transfer

> Sparse + Black-box

> Sparse + VLM

都可以研究。

---

# 25. ViT Attack

攻击对象：

> Vision Transformer

传统 CNN：

```
CNN
 ↓
局部卷积
 ↓
Feature
```

ViT：

```
Image
 ↓
Patch
 ↓
Transformer
 ↓
Attention
```

所以可以研究：

> Patch、Attention、Token、Feature 等层面的攻击。

例如：

```
Patch 1
Patch 2
Patch 3
...
 ↓
Transformer
```

攻击某些 patch/token，使 attention pattern 发生变化。

### 前景：★★★★☆

单独做：

> “攻击 ViT”

已经比较成熟。

但：

> **ViT + Transfer + Feature Alignment**

仍然很有研究空间。

---

# 26. Multi-view Clustering Attack

对象：

> Multi-view Clustering

例如一个数据同时有：

```
View 1：图片
View 2：文本
View 3：属性
```

正常：

```
多视图
 ↓
融合
 ↓
Cluster
```

攻击：

```
修改一个或几个 view
 ↓
聚类结构发生变化
```

例如：

```
原本：

AAA BBB CCC

攻击后：

AA  BBBB CC
```

### 前景：★★★☆

比较偏传统机器学习。

如果你未来准备：

> 对抗学习 + 多视图学习

可以考虑。

但是如果你想冲目前比较热门的方向，我不会优先选它。

# 27. Object Detection Attack

分类：

```
图片 → 猫
```

检测：

```
图片
 ↓
猫：位置1
狗：位置2
汽车：位置3
```

攻击目标就更多：

```
让目标消失
让模型产生错误目标
让框的位置错误
让类别错误
```

例如：

```
真实：

🚗

检测：
car 99%
```

攻击：

```
检测不到 car
```

### 前景：★★★★☆

尤其适合：

> Autonomous Driving / Physical Attack

但纯数字攻击已经比较成熟。

# 28. Semantic Segmentation Attack

检测：

```
有没有这个物体？
在哪里？
```

分割：

```
这个像素属于谁？
```

例如：

```
道路道路道路
汽车汽车汽车
行人行人
```

攻击：

```
道路 → 汽车
汽车 → 背景
```

也就是攻击 pixel-level prediction。

### 前景：★★★★☆

尤其：

> segmentation + foundation model

> SAM + adversarial attack

比较值得研究。

# 29. Pedestrian Re-identification Attack

简称：

> Person Re-ID

目标：

```
摄像头 A
 ↓
识别某个人

摄像头 B
 ↓
判断是不是同一个人
```

攻击：

```
A
 ↓
攻击
 ↓
B
```

可以让系统：

```
认不出来
```

或者：

```
把 A 认成 B
```

### 前景：★★★☆

实际安全意义很强。

但相比：

> VLM / LLM / Agent

现在学术热度没有那么高。

# 30. Image Compression Attack

利用：

```
JPEG
PNG
视频压缩
```

对攻击样本产生影响。

有两个研究方向。

### 方向 A

攻击样本经过压缩后：

```
攻击失效
```

研究：

> 如何提高攻击对 compression 的鲁棒性。

### 方向 B

利用 compression 本身作为攻击因素：

```
原始图片
 ↓
特定压缩
 ↓
模型错误
```

### 前景：★★★☆

如果和：

> Physical-world / Robust Transfer Attack

结合，价值会更高。
