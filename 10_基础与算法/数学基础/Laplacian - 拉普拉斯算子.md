# Laplacian - 拉普拉斯算子


现在学拉普拉斯算子其实非常合适，因为它也是机器学习、图像处理、PDE、图神经网络里非常重要的数学工具。

我建议你按这个顺序理解：

> **导数 → 二阶导数 → 多元函数 → 梯度 → 拉普拉斯算子 → 几何意义 → 拉普拉斯矩阵 → 机器学习应用**

---

# 1. 先从一维的“变化率”开始

假设有一个函数：

$$f(x)=x^2$$

一阶导数：

$$f'(x)=2x$$

它表示：

> **函数在某个位置变化得有多快。**

例如 $x=2$：

$$f'(2)=4$$

说明在 $x=2$ 附近，函数正在快速增加。

---

## 再求一次导数

$$f''(x)=2$$

二阶导数描述的是：

> **变化率本身变化得有多快。**

所以：

- 一阶导数 → 变化率
- 二阶导数 → 变化率的变化率

---

# 2. 从一维进入二维

现在我们有一个二维函数：

$$f(x,y)$$

例如：

$$f(x,y)=x^2+y^2$$

因为现在有两个变量，所以我们可以分别研究：

$$\frac{\partial f}{\partial x}$$

和：

$$\frac{\partial f}{\partial y}$$

对于这个函数：

$$∂f∂x=2x\frac{\partial f}{\partial x}=2x$$ $$∂f∂y=2y\frac{\partial f}{\partial y}=2y$$

把它们放在一起，就是**梯度**：

$$\boxed{ \nabla f= \begin{bmatrix} \frac{\partial f}{\partial x}\\ \frac{\partial f}{\partial y} \end{bmatrix} }$$

对于：

$$f(x,y)=x^2+y^2$$

有：

$$\nabla f= \begin{bmatrix} 2x\\ 2y \end{bmatrix}$$

---

# 3. 那么拉普拉斯算子是什么？

终于到重点。

拉普拉斯算子通常写成：

$$\boxed{\nabla^2}$$

或者：

$$\boxed{\Delta}$$

对于二维函数：

$$f(x,y)$$

定义：

$$\boxed{ \nabla^2f = \frac{\partial^2f}{\partial x^2} + \frac{\partial^2f}{\partial y^2} }$$

注意！

**拉普拉斯算子就是把每个维度的二阶偏导数加起来。**

---

# 4. 举个最简单的例子

还是：

$$f(x,y)=x^2+y^2$$

先求：

$$\frac{\partial f}{\partial x}=2x$$

再求一次：

$$\frac{\partial^2f}{\partial x^2}=2$$

同理：

$$\frac{\partial f}{\partial y}=2y ∂2f∂y2=2\frac{\partial^2f}{\partial y^2}=2$$

所以：

$$\boxed{ \nabla^2f=2+2=4 }$$

---

# 5. 三维怎么办？

如果：

$$f(x,y,z)$$

那么：

$$\boxed{ \nabla^2f= \frac{\partial^2f}{\partial x^2} + \frac{\partial^2f}{\partial y^2} + \frac{\partial^2f}{\partial z^2} }$$

所以你可以把拉普拉斯算子记成：

> **所有方向上的二阶偏导数之和。**

---

# 6. 为什么叫“算子”？

这里很多初学者容易疑惑。

$$\nabla^2$$

本身不是一个普通数字，它是一个**操作**。

例如：

$$\nabla^2$$

作用到：

$$f(x,y)$$

上：

$$\nabla^2f$$

就得到：

$$\frac{\partial^2f}{\partial x^2} + \frac{\partial^2f}{\partial y^2}$$

所以：

> **算子可以理解成“一个专门对函数进行某种操作的东西”。**

类似于：

$$\frac{d}{dx}$$

也是一个算子。

---

# 7. 拉普拉斯算子最重要的直觉：看“弯曲程度”

这是你真正应该理解的地方。

例如：

$$f(x)=x^2$$

它是一条向上的抛物线。

二阶导：

$$f''(x)=2>0$$

说明它整体是：

> **向上弯的。**

如果：

$$f(x)=-x^2$$

那么：

$$f''(x)=-2<0$$

说明：

> **向下弯。**

---

二维情况下也是类似的。

拉普拉斯算子：

$$\nabla^2f$$

可以粗略理解为：

> **函数在当前位置周围的“总体弯曲程度”。**

---

# 8. 一个非常重要的直觉：和周围平均值比较

拉普拉斯算子还有一个特别漂亮的理解。

假设某个点：

$$f(x,y)$$

比周围的点都高很多。

那么这个地方像一个：

> **山顶**

例如：

```
       高
       ●
     /   \
   /       \
```

在山顶附近：

$$\nabla^2f<0$$

因为中心点比周围高。

---

如果某个点比周围都低：

```
   \       /
     \   /
       ●
```

这是一个：

> **山谷**

那么：

$$\nabla^2f>0$$

---

如果一个区域非常平：

```
────────────
```

那么：

$$\nabla^2f\approx0$$

所以可以建立一个非常重要的直觉：

$$\boxed{ \begin{array}{c|c} \nabla^2f>0 & \text{更像山谷}\\ \nabla^2f<0 & \text{更像山顶}\\ \nabla^2f=0 & \text{局部比较平衡} \end{array} }$$

---

# 9. 为什么拉普拉斯算子和“周围”有关？

因为二阶导数本质上是在比较：

> **当前位置和附近位置之间的变化。**

在一维情况下：

$$f''(x)$$

可以近似写成：

$$\boxed{ f''(x) \approx \frac{f(x+h)-2f(x)+f(x-h)}{h^2} }$$

这个公式特别重要。

把它整理一下：

$$f''(x) \approx \frac{ f(x+h)+f(x-h)-2f(x) }{h^2}$$

你会发现：

$$f(x+h)+f(x-h)$$

是左右邻居。

而：

$$2f(x)$$

是中心点。

所以二阶导数实际上在比较：

> **中心点和邻居之间的差异。**

---

# 10. 这就连接到机器学习里的“拉普拉斯矩阵”

如果你以后学习：

- 图机器学习
- GNN
- 图神经网络
- 谱聚类
- 半监督学习
- 流形学习

你一定会遇到：

$$\boxed{L=D-A}$$

这就是**图拉普拉斯矩阵（Graph Laplacian）**。

这里：

- $A$：邻接矩阵
- $D$：度矩阵
- $L$：拉普拉斯矩阵

---

# 11. 举一个最简单的图

假设三个节点：

```
1 —— 2 —— 3
```

邻接矩阵：

$$A= \begin{bmatrix} 0&1&0\\ 1&0&1\\ 0&1&0 \end{bmatrix}$$

每个节点连接的数量：

$$D= \begin{bmatrix} 1&0&0\\ 0&2&0\\ 0&0&1 \end{bmatrix}$$

于是：

$$L=D-A$$

得到：

$$\boxed{ L= \begin{bmatrix} 1&-1&0\\ -1&2&-1\\ 0&-1&1 \end{bmatrix} }$$

你看这个矩阵的形式：

$$\begin{bmatrix} 1&-1&0\\ -1&2&-1\\ 0&-1&1 \end{bmatrix}$$

是不是和刚才的：

$$f(x+h)-2f(x)+f(x-h)$$

有点像？

**这不是巧合。**

---

# 12. 图拉普拉斯为什么也是“二阶变化”？

假设三个节点上的特征值是：

$$x= \begin{bmatrix} x_1\\ x_2\\ x_3 \end{bmatrix}$$

那么：

$$Lx = \begin{bmatrix} x_1-x_2\\ 2x_2-x_1-x_3\\ x_3-x_2 \end{bmatrix}$$

中间节点：

$$2x_2-x_1-x_3$$

实际上就是：

$$\boxed{ 2\times\text{中心}-\text{左邻居}-\text{右邻居} }$$

这和连续空间里的二阶导数高度对应。

所以你可以把它理解成：

> **连续空间里的拉普拉斯算子 → 图上的拉普拉斯矩阵**

---

# 13. 为什么 GNN 特别喜欢拉普拉斯？

因为 GNN 的一个核心思想就是：

> **一个节点应该从自己的邻居那里获取信息。**

例如：

```
      A
      |
B —— C —— D
      |
      E
```

节点 C 的新特征可以和：

$$A,B,D,E$$

这些邻居有关。

而拉普拉斯矩阵本质上就是在描述：

> **节点和它邻居之间的差异。**

所以它非常适合描述：

> **图上的平滑性、局部变化和邻居关系。**

---

# 14. 和你刚刚学的协方差矩阵有什么区别？

这个非常值得对比。

|       | 协方差矩阵     | 拉普拉斯               |
| ----- | --------- | ------------------ |
| 主要描述  | 特征之间共同变化  | 空间/图上的局部变化         |
| 核心思想  | 两个变量一起怎么变 | 一个点和邻居差多少          |
| 常见形式  | $\Sigma$  | $\nabla^2$、$L=D-A$ |
| PCA   | 非常重要      | 不是核心               |
| 图神经网络 | 间接        | 非常重要               |
| 谱聚类   | 不核心       | 非常重要               |

# 16. 你现在最需要掌握的几个公式

先不要背一大堆，只掌握这几个。

### 一维

$$\boxed{ \nabla^2 f=f'' }$$

### 二维

$$\boxed{ \nabla^2f= f_{xx}+f_{yy} }$$

也就是：

$$\boxed{ \nabla^2f= \frac{\partial^2f}{\partial x^2} + \frac{\partial^2f}{\partial y^2} }$$

### 三维

$$\boxed{ \nabla^2f= f_{xx}+f_{yy}+f_{zz} }$$

### 图拉普拉斯

$$\boxed{ L=D-A }$$

这四个公式先吃透。

---

## 最后给你一个非常关键的理解

你不要把拉普拉斯算子简单记成：

> “二阶导数相加。”

这只是**公式层面的定义**。

真正应该形成的理解是：

> **一阶导数看“往哪里变化”；二阶导数看“变化本身怎么变化”；拉普拉斯算子把各个方向上的二阶变化汇总起来，因此可以用来描述一个函数在某一点附近的总体弯曲程度，以及这个点与周围的差异。**

而到了机器学习：

> **把连续空间离散成节点和边，就得到图拉普拉斯矩阵 $L=D-A$。**

这就是为什么你以后会在 **PCA、谱聚类、流形学习、图神经网络、图信号处理**等不同地方反复看到“拉普拉斯”这个词。
