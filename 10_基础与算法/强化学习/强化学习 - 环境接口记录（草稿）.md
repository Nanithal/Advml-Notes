# 强化学习 - 环境接口记录（草稿）

# 环境
```
env.resert与env.step在被调用时，会返回环境当前的状态

# reset 返回
env_obs = env.reset(usr_conf=usr_conf)
# step 返回
env_reward, env_obs = env.step(hero_actions)

```

**env_reward**包含以下信息：

|   数据名    |  数据类型  | 数据描述 |
| :------: | :----: | :--: |
| frame_no |  int   | 当前帧号 |
|  env_id  | string | 环境标识 |
|  reward  | float  | 当前得分 |
**env_obs**包含以下信息：

|     数据名     |    数据类型     |       数据描述        |
| :---------: | :---------: | :---------------: |
|   env_id    |   string    |       环境标识        |
|  frame_no   |     int     |       当前帧号        |
| observation | Observation |       观测信息        |
| extra_info  |  ExtraInfo  |       额外信息        |
| terminated  |    bool     |   任务是否结束（被怪物捕获）   |
|  truncated  |    bool     | 任务是否因达到最大步数或异常而截断 |
|             |             |                   |
