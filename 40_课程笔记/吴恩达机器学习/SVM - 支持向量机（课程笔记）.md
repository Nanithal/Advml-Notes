# SVM - 支持向量机（课程笔记）


n个样本，m维度，两种类别-----如何设计（m-1）维度的超平面（决策边界、缓冲区）将两类数据区分开来
SVM 分割超平面通用表达式：$w^Tx+b=w_1​x_1​+w_2​x_2​+⋯+w_m​x_m​+b=0$

## 目标

两类数据到决策边界的距离（margin）都足够大，则可转换为求解两类数据间隔（离决策边界最近的正负样本到决策边界的距离之和）最大，这时的间隔称为硬间隔（Hard Margin）
![[40_课程笔记/吴恩达机器学习/attachment/Pasted image 20260623190919.png]]

## 支持向量（Support Vector）

决策边界上下移动之时最先与两类数据相交的那两个数据点所组成的向量叫做支持向量。由于w和
b的改变不会影响超平面，则那么最终决策边界上下移动后均可转换为 = 正负1（正负超平面）
![[40_课程笔记/吴恩达机器学习/attachment/Pasted image 20260623192950.png]]


## 损失因子
![[40_课程笔记/吴恩达机器学习/attachment/Pasted image 20260623193346.png]]

确定好决策边界之后，异常值的影响需要引进损失因子来衡量，此时目标变为在考虑损失因子的情况下取最大化间隔（间隔最大化与损失最小化之间找到平衡），此时的间隔也称为**软间隔**（Soft Margin）

## 升维转换

当存在低纬度数据**无法找到直线**（线性不可分）作为决策边界之时，便可以通过合适的**维度转换函数**$T(x)$让数据**增加一个维度**在找相应的超平面(新维度下的) 作为决策边界。这样子后，当加入要分类的新数据时，便也可以先对其进行升维，再根据高纬度下的决策超平面进行判断。
但升维需要明确的维度转换函数，这时候便要用到**Kernel Trick**（核技巧、核函数）。
![[40_课程笔记/吴恩达机器学习/attachment/Pasted image 20260623194906.png]]

## 求解 $w$ 和 $b$
1. 对正超平面和负超平面上的两点均满足相应平面的方程，相减得到$w_1(x_{1m}-x_{1n})+w_2(x_{2m}-x_{2n})=2$，则可以做 $\vec{w}(\vec{x_m}-\vec{x_n}) =2$
2. 决策边界上取两点也相减，得到 $\vec{w}$ 垂直于决策超平面
3. 向量点积定义展开得间隔 $L$ =$2/\| \boldsymbol{\vec{w}}\|_2$
4. 则目标为在约束调节下最小化w
5. 由于超平面的正负性且为了方便，并使用**拉格朗日乘子法**最后目标即为
